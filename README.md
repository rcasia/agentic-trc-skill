# Agentic TCR Workflow Skill

A concise agent skill for working within the **Agentic TCR Workflow**: develop incrementally, cross the mutation verification boundary, and continue from the same execution context after acceptance or recovery.

The skill defines agent behavior; the normative workflow is defined by the [Agentic TCR Workflow RFC](https://github.com/rcasia/agentic-tcr-workflow-rfc).

See [`SKILL.md`](./SKILL.md) for the operational rules.
